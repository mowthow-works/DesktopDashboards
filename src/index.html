外部サービス接続（SaaS 連携）

📖 Notion 連携の設定手順（4ステップ）
  1. https://app.notion.com/developers/connections で + New connection → 名前を入力（空欄だと Create ボタン無効）→ Authentication method で API token（旧 Internal Integration 相当）を選んで Create connection
  2. Capabilities で Read content に加え、チェック書き戻しを行う場合は Update content を確認し、発行されたトークン（ntn_...）を下の「＋ 接続を追加」から保存（送信先 api.notion.com、Windows 資格情報マネージャー保管）
  3. Notion 側の対象データベース右上の ⋯ → コネクト (Connections) からコネクトを追加、または開発者コンソールの Content access タブから親ページを選択して共有（※未共有だと object_not_found エラー）
  4. 対象 DB に タイトル (title)・日付 (date)・完了チェック (checkbox) の 3 プロパティを用意し、ガジェットの「⚙ ウィジェット設定」へ DB ID（または DB URL）を入力して保存
