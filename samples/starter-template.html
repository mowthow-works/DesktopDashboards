ローカル HTML ガジェット作成ガイド

  • このファイル（samples/starter-template.html）を任意のフォルダへコピーして自由に編集できます。
  • 同じフォルダ・サブフォルダ内の資産（./style.css、./app.js、画像等）は相対パスで読み込めます。
  • 上端 28px に操作バーが表示されるため、body に padding-top: 32px 程度を確保すると操作しやすくなります。
  • 管理画面の「カスタム CSS」から body { background: transparent !important; } のような上書きも可能です。
  • 外部リンク（https://...）はガジェット内ではなく OS の既定ブラウザで開きます。
